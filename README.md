# Bastyle Blacklist

Версия: `v1.0.0`

Telegram-бот для модерации медиа в чате. Администратор может добавить медиафайл в черный список командой `/ban`, после чего бот будет удалять повторные сообщения с этим же файлом.

## Возможности

- проверка прав администратора перед баном;
- блокировка фото, GIF-анимаций, стикеров и видео по `FileUniqueID`;
- удаление заблокированных медиа из обычных сообщений и reply-сообщений;
- обработка обновлений через пул из нескольких worker'ов.

## Команды

- `/hello` - проверочная команда, отвечает `Hello, World!`;
- `/ban` - добавляет медиа из сообщения, на которое сделан reply, в черный список и удаляет это сообщение. Доступна только администраторам чата.

## Настройка

Создайте файл `.env` в корне проекта:

```env
TOKEN="your-telegram-bot-token"
```

Токен можно получить у `@BotFather` в Telegram.

## Запуск

Локально:

```bash
go run ./cmd/main.go
```

Через Docker:

```bash
docker build -f build/Dockerfile -t bastyle-blacklist .
docker run --env-file .env bastyle-blacklist
```

## Требования

- Go `1.25.4` или совместимая версия;
- Telegram Bot API token;
- права администратора у бота в чате, где он должен удалять сообщения.
