# Тесты

Документ описывает существующее тестовое покрытие проекта и сценарии, которые
проверяются в тестах.

## Запуск

| Модуль                       | Команда                                              | Что запускает                                                                                                                           |
|------------------------------|------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| Go-бот                       | `cd services/bot && make test`                       | Unit и функциональные тесты Go-бота без build tag `integration`. Часть функциональных тестов поднимает PostgreSQL через testcontainers. |
| Go-бот, интеграционные тесты | `cd services/bot && go test -tags integration ./...` | Тесты с внешними зависимостями, например PostgreSQL через testcontainers.                                                               |
| AI matcher                   | `make -C services/aimatcher test`                    | Pytest-тесты Python/FastAPI сервиса.                                                                                                    |

Интеграционные тесты с PostgreSQL используют testcontainers и требуют доступный
Docker. Тесты FFmpeg пропускаются, если бинарный файл `ffmpeg` недоступен.
Тест `test_real_model.py` загружает реальную embedding-модель и зависит от
окружения для запуска Transformers.
